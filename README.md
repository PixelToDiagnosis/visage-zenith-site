# Lumina Clinic

Create a premium bilingual website for an aesthetic medicine doctor.

The website must be elegant, warm, sophisticated and medical, similar to a high-end aesthetic clinic. The goal is to attract new patients, build trust and encourage consultation bookings.

LANGUAGES  
The entire website must be fully bilingual:
French (FR) and Dutch (NL)

Default language: French.  
Include a language switcher in the top navigation.

---

DESIGN STYLE

Style: luxury aesthetic clinic, minimalist, calm and medical.

Color palette:
- Cream (#F7F3EE)
- Soft beige (#E6D7C9)
- Light taupe (#BFAFA3)
- Off white (#FAF8F6)
- Optional subtle gold accent (#C9A97A)

Typography:
- Elegant serif for titles (Playfair Display or Cormorant)
- Modern sans-serif for body text (Inter or Lato)

Design principles:
- Spacious layout
- Soft natural lighting images
- Calm atmosphere
- Premium aesthetic clinic feeling
- Mobile-first design

Images should show:
- natural skin
- aesthetic treatments
- doctor consultation
- elegant clinic interiors
