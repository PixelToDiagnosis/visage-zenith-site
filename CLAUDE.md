# Website Dr Marie-Eve Bousmar – aesthetic medicine (Asse & Laken)

Public website of Dr Marie-Eve Bousmar's aesthetic medicine practice, live at www.drmarieevebousmar.be.
React + Vite + Tailwind (originally generated by Lovable), hosted on Netlify (see netlify.toml).
The site owner is a doctor, not a developer: explain things in plain language and never ask her to run commands.

## Workflow rules
- Never push directly to main. Work on a new branch and open a pull request.
- Netlify posts a Deploy Preview link on every pull request; tell her to check it on laptop and phone before merging.
- In the pull request description, list in plain words what changed on which page.
- Make sure the site still builds (`npm install` then `npm run build`, or `bun run build`) before opening the pull request.
- Keep the existing design: same fonts, colours, spacing and components. Reuse existing page layouts for new pages.
- Check that every change also looks good on mobile.
- Compress new images and give every image a descriptive alt text.
- Keep netlify.toml as it is (it holds the build settings and the page-routing rule).
- When adding a treatment page, also add its slug to scripts/generate-sitemap.ts.

## Content rules
- The site is bilingual: Dutch (nl) and French (fr). Every text change must be made in BOTH languages.
- Tone: calm, professional, medical. No hype.
- Belgian rules restrict advertising for aesthetic medicine. Keep new text factual and informative:
  no promotional language, discounts or new before/after images unless Marie-Eve explicitly confirms them.
- Never invent medical claims, prices or results. Ask if information is missing.
